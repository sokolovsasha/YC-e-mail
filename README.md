# YCLIENTS Email Helper

Расширение для Google Chrome, которое превращает email-адреса клиентов на страницах YCLIENTS в кликабельные ссылки `mailto:` и добавляет рядом с ними иконку ✉️. Один клик — и открывается почтовый клиент по умолчанию с уже заполненным полем «Кому».

## Возможности

- **Кликабельные email** — любой email на странице превращается в ссылку `mailto:`.
- **Эмодзи-иконка** рядом с адресом — визуальный маркер и дополнительная кнопка для отправки письма.
- **Виртуализированные таблицы** — корректно обрабатывает строки, которые подгружаются по мере прокрутки.

## Поддерживаемые страницы

| Страница | Пример URL |
|---|---|
| Расписание | `https://yclients.ru/timetable/<salon-id>/#mode=1&main_date=...` |
| Клиентская база | `https://yclients.com/clients/<salon-id>/base?fields[...]` |
| Раскрытая карточка клиента | там же (email в `<input name="email">`) |

Покрываются также поддомены (`*.yclients.ru`, `*.yclients.com`) и iframe-фреймы (`all_frames: true`).

## Установка

Расширение не опубликовано в Chrome Web Store, устанавливается вручную в режиме разработчика.

1. Скачайте и распакуйте в любую папку https://github.com/sokolovsasha/YC-e-mail/archive/refs/heads/main.zip
2. Откройте `chrome://extensions/` в Chrome.
3. Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку проекта.
5. Откройте одну из поддерживаемых страниц YCLIENTS — рядом с email должна появиться иконка ✉️.
